# NCMS 사용자 중심 신규 고객사 등록 및 노코드(No-Code) PDF 기반 명함 템플릿 에디터 명세서

| 항목 | 내용 |
|---|---|
| 문서명 | PDF 단일 포맷 및 10초 온보딩 마법사 기반 초간단 세팅 기술 명세서 & 사용자 가이드 |
| 작성일 | 2026-08-10 (v3.3 사용자 운영 매뉴얼 추가 개편) |
| 작성 목적 | 개발자의 소스코드 수정이나 재배포 없이, 로그컴 관리자가 웹 UI에서 회사명 입력, 로고/PDF 파일 업로드만으로 신규 고객사 세팅 및 명함 템플릿을 10초 만에 완공하는 초간단 시스템 설계 명세 및 운영자 조작 매뉴얼 |
| 대상 | 로그컴 운영팀, 고객사 관리자, NCMS 개발팀 |

## 1. 개요 및 핵심 원칙

신규 고객사 등록과 명함 템플릿 세팅을 **단 하나의 통합 마법사(Wizard) UI**로 연결하여 관리자의 입력 및 운영 부담을 최대로 줄입니다.

1. **초간단 고객사 세팅 (10-Second Company Onboarding)**:
   - 한글 회사명 입력 시 URL 코드 자동추천 (`(주)카카오` $\rightarrow$ `kakao`)
   - 로고 이미지 1개 업로드로 브랜딩 끝
2. **PDF 단일 표준화 & 스마트 프리셋 (Single PDF & Smart Preset)**:
   - 명함 시안 PDF 1개 업로드 후 `[우하단형]` 프리셋 클릭 한 번으로 양면 템플릿 자동 구축
3. **초대 링크 단일 복사 (Simple Invite Link Copy)**:
   - 메일 자동 발송 등 복잡한 연결 없이, 완료 화면에서 `[초대 링크 복사]` 버튼 하나만 클릭하면 끝 (운영자가 카톡/메일 등으로 직접 전달)

## 2. 📖 [실제 사용자 매뉴얼] 10초 신규 세팅 3-Step 가이드

실제 로그컴 운영자(비개발자)가 신규 고객사를 세팅할 때 진행하는 **초간단 3단계 조작 가이드**입니다.

```mermaid
flowchart LR
    S1["1단계: 회사명 & 로고 입력"] --> S2["2단계: PDF 시안 업로드 & 프리셋 클릭"]
    S2 --> S3["3단계: 오픈하기 & 초대 링크 복사"]
```

### 🔹 1단계: 회사 정보 입력 (소요시간 3초)
1. 로그컴 관리자 화면(`/admin/companies`)에서 상단의 **`[+ 10초 신규 고객사 세팅]`** 버튼을 클릭합니다.
2. **회사명** 입력란에 회사 이름을 적습니다. (예: `(주)카카오`)
   * *자동 처리*: 회사명을 적으면 접속 주소(`logcom.co.kr/kakao`)가 자동으로 세팅됩니다.
3. **로고 이미지** 상자에 회사 로고(PNG 파일)를 마우스로 쓱 끌어다 놓습니다(Drag & Drop).

---

### 🔹 2단계: 명함 시안 PDF 업로드 & 프리셋 선택 (소요시간 5초)
1. 고객사에서 전달받은 **명함 시안 PDF 파일(1p: 앞면, 2p: 뒷면)**을 업로드 상자에 끌어다 놓습니다.
2. 화면에 나타난 3가지 프리셋 버튼 중 명함 시안과 가장 비슷한 형태를 **클릭**합니다.
   * **`[우측 하단 정렬형]`** : 이름/전화번호가 오른쪽 아래에 위치한 일반 명함
   * **`[좌측 하단 정렬형]`** : 이름/전화번호가 왼쪽 아래에 위치한 명함
   * **`[중앙 정렬형]`** : 문구가 가운데에 깔끔하게 배치된 명함
3. *필요 시*: 마우스로 성명/전화번호 텍스트 묶음을 살짝 끌어서 1~2mm 위치를 맞춥니다.

---

### 🔹 3단계: 서비스 오픈 & 담당자 링크 전달 (소요시간 2초)
1. **`[🚀 고객사 서비스 오픈]`** 버튼을 누릅니다.
2. 완료 팝업창에 나타난 **`[📋 초대 링크 복사]`** 버튼을 클릭합니다.
3. 복사된 링크(`https://logcom.co.kr/kakao/invite?token=...`)를 카카오 담당자에게 **카카오톡이나 이메일로 전달**하면 모든 세팅이 완료됩니다!
   * *고객사 담당자*: 전달받은 링크를 클릭하여 본인의 관리자 아이디/비밀번호를 설정한 뒤 바로 임직원 명함 발주 서비스를 이용하기 시작합니다.

## 3. PDF 단일 포맷 기반 초간단 템플릿 에디터 명세

### 3.1 스마트 프리셋 & 자동 감지
* **PDF 텍스트 좌표 자동 감지**: PDF 내부 텍스트("홍길동", "010-XXXX") 위치 자동 인식
* **레이아웃 프리셋**: `우측 하단형`, `좌측 하단형`, `중앙 분할형` 버튼 1번 클릭으로 텍스트 그룹 자동 위치 조절
* **PDF 1개로 양면 자동 분할**: PDF 1p는 앞면, 2p는 뒷면 배경으로 1초 변환

## 5. 최종 구현 및 운영 비교

| 구분 | 기존 계획 | **초간단 All-in-One 마법사 (최종 개편안)** |
|---|---|---|
| **고객사 등록** | 코드, 회사명, HEX 색상, 로고 일일이 입력 | **회사명 입력 + 로고 드롭 (컬러 선택 없음)** |
| **명함 템플릿** | 템플릿 메뉴 가서 개별 작업 | **마법사에서 PDF 올리고 프리셋 클릭 시 자동 완성** |
| **관리자 계정** | 관리자가 메일 발송 로직 개발 | **화면에서 `[초대 링크 복사]` 클릭 후 카톡/메일에 자유롭게 전달** |
| **총 소요 시간** | 약 5분 ~ 10분 | **단 10초 ~ 20초 (클릭 3번)** |
